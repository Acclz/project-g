# 项目zz · 经营归因分析系统

面向企业核心经营场景的智能多维归因分析系统：指标树因子拆解、自动假设生成、统计检验验证、业务大事件因果关联，支持多轮下钻追问、What-If 策略推演与结构化归因报告导出。

一句话：**仪表盘只能告诉你"销售额掉了 8%"，这个项目要回答"这 8% 里，多少是渠道结构变了、多少是某个品类断货、多少是噪声"。**

## 技术栈（已定）

Python 3.12 · FastAPI · SQLAlchemy 2 · Alembic · PostgreSQL 16 · Vue 3 + Vite · 云端 DeepSeek（仅用于假设草案与报告文字）· 受限子进程数据沙箱（**不依赖 Docker**）

## 数据说明（诚实声明）

* 本项目的多维数仓为**合成数据**，由固定种子的生成器产出，可复现。
* 合成数据**预埋已知真因**，因此归因准确率可以量化；但对外必须声明"准确率类指标基于合成数据集"。
* 守恒误差、沙箱越权拦截率、并发一致性、接口 P95 等指标与数据真假无关，属硬指标。
