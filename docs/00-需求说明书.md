## 0. 项目定位

面向企业核心经营场景的**智能多维归因分析系统**：围绕经营指标的异常波动，做指标树因子拆解、自动假设生成、统计检验验证、业务大事件因果关联，并支持多轮下钻追问、What-If 策略推演与结构化归因报告导出。

一句话说明它解决什么：**仪表盘只能告诉你"销售额掉了 8%"，本系统要回答"这 8% 里，多少是渠道结构变了、多少是某品类断货、多少是噪声"。**

### 0.1 本项目的特点与边界（诚实声明）

* **数据全部合成**，但**带已知真值**：合成数仓由生成器构造，同时产出"真因清单"（哪一天、哪个维度、由哪个因子驱动、贡献多少）。因此归因准确率是可算的，但**必须在材料里明示"准确率类指标基于合成数据集"**。
* **性能与一致性类指标与数据真假无关**：守恒误差、沙箱越权拦截率、并发会话隔离、接口 P95，这些是硬指标。
* 不追求"AI 什么都懂"：数值计算全部由确定性算法完成，**大模型只负责生成假设草案、SQL 草案与报告文字**，且每一条结论都必须落到可复现的查询与数值上。

### 0.2 两个业务场景（原文要求至少两个）

| 场景 | 根指标 | 分解方法 | 覆盖的方法论能力 |
| --- | --- | --- | --- |
| A 电商零售 | GMV（支付成功口径） | 乘法模型 | LMDI、交叉残差消除、渠道/品类结构变化 |
| B 快消品 | 毛利额 | 加法模型（外层）+ 乘法模型（内层） | 差额分析、混合树、成本驱动 vs 价格驱动 |

## 1. 交付形式

1. **可运行前端**：异动大盘 + 三栏交互式归因工作台 + 事件日历 + 指标字典 + 报告归档导出（共 5 个页面）。
2. **后端服务**：指标与公式引擎、意图理解与规划调度、安全数据分析沙箱、因果关联与事件引擎、What-If 模拟引擎、会话与报告管理。
3. **合成多维数仓数据集**：18 个月、日粒度，含渠道/品类/区域/客群四维与两类业务事实。
4. **仿真案例**：电商大促后 GMV 下滑、快消原料涨价叠加渠道佣金调整导致毛利异动，各含一条完整演示链路。
5. **多格式报告导出**：Markdown、PDF、Excel 三种格式，内容与页面一致。
6. **评测集与报告**：归因评测集（预埋真因）、伪相关陷阱集、沙箱对抗测试集。
7. **材料**：术语与口径手册、面试问答册、威胁模型、安全审查报告、界面截图、一键演示脚本。

## 2. 开发范围

### 2.1 能力表（按"异动 → 归因 → 交付"链路逐环节拆解）

| 环节 | 能力 | 关键约束 |
| --- | --- | --- |
| 指标建模 | 指标字典（原子/派生/复合）、指标树、口径校验、维度枚举 | 复合指标必须可解析为可加或可乘结构；口径变更留版本 |
| 异动发现 | 大盘监控、阈值与基线、异动清单与一键发起 | 支持同比/环比；异动判定必须可解释（阈值 + 基线） |
| 因子拆解 | 加法模型（差额分析）、乘法模型（LMDI）、混合树逐层分解 | 每层强制守恒：`|Σ贡献 − Δ目标| < 1e-9` |
| 维度下钻 | 多维交叉下钻、TOP 组合定位、透视表 | 下钻必须继承上一层锁定切片，不得静默扩大范围 |
| 假设生成 | 基于异动特征自动生成 3~5 条候选假设 | 每条假设必须附带可执行探查代码与预期方向 |
| 沙箱验证 | 在受限环境中执行 SQL / Python 探查 | 无网络、只读角色、配额受限、全量审计 |
| 统计检验 | 相关性、显著性、置信度打分 | 显著性口径固定：置换检验（可复现随机种子） |
| 伪相关排除 | 识别"同步变化但同源"的因子 | 必须给出排除理由（共同驱动源或时间不一致） |
| 事件关联 | 业务事件日历、异动窗口前后 3 日匹配 | 事件作为外生解释变量入链，防止误判为内部操作问题 |
| 策略推演 | What-If 单点弹性 + 参数曲线 | 必须标注区间与假设条件，禁止给出无依据的精确值 |
| 多轮会话 | 追问、切片继承、上下文锁定、结果过期标记 | 数据或口径变化后标记旧结论过期 |
| 报告交付 | 七段式报告组装、三格式导出、批注留痕 | 导出内容与页面展示必须一致（同一份结构化中间态） |
| 治理 | 认证、角色权限、审计日志、运行日志 | 审计记录只读、不可删除 |

### 2.2 明确不做（范围外，见确认书 §7.2 台账）

通用数据源接入向导；报告多人协同编辑；模型微调（原文第 3 章）；容器化沙箱；DuckDB/列存引擎；杜邦分析法；桑基图；历史归因案例库检索；真实外部数据抓取与外部系统对接。

## 3. 用户角色与权限

| 角色 | 职责 | 权限边界 |
| --- | --- | --- |
| `经营分析师` | 创建归因会话、设定目标指标与基期、输入探查问题、调优拆解逻辑、审核证据链、调参推演、发布与导出报告 | 自己创建的会话全权；他人会话只读（可复制为新会话） |
| `业务负责人 / 管理层` | 查看指标异动大盘、查看结构化结论与量化贡献率、查看行动项、导出简报 | 只读；不可修改指标定义与拆解逻辑 |
| `系统与数据管理员` | 维护指标元数据与拆解公式、维护业务事件日历、配置模型参数与沙箱配额、审计查询 | 可改配置；**不可改历史会话结论**；审计记录只读 |

**权限规则**：认证采用统一登录（JWT）；角色为 RBAC 三角色；资源级隔离按"会话归属 + 数据集范围"；管理员的操作全部留痕，且**任何角色都不能删除审计记录**。

## 4. 页面需求

### 4.1 指标异动大盘页

* 核心经营指标卡片：当前值、环比、同比、与基线带（正常波动区间）的位置。
* 异动清单：按严重度排序，展示指标、期间、变动幅度、Z 分数、是否已发起归因。
* 一键发起"智能归因分析"：带上指标、对比期间、基期，直接进入工作台并创建会话。
* 快捷入口：切换指标域（电商零售 / 快消品）、进入事件日历、查看最近报告。

### 4.2 归因分析工作台（三栏）

| 区域 | 内容 | 交互 |
| --- | --- | --- |
| 左：会话与指标导航区 | 历史会话列表；当前目标指标概览（口径版本、对比期间、基期值/现期值/总差异） | 切换会话、新建分析、复制他人会话 |
| 中：对话与探索交互区 | 自然语言输入与多轮追问；**流式展示**分析路径（识别异动 → 拆解 → 下钻 → 假设 → 验证 → 事件关联 → 结论）；沙箱执行过程与统计结论 | 追问、要求重算、指定维度下钻、锁定/解锁切片 |
| 右：动态归因看板区 | 因子贡献瀑布图、多维下钻透视表、核心归因结论卡片、行动项清单、What-If 推演面板、一键导出报告 | 排序与折叠透视表、调参推演、导出 Markdown/PDF/Excel |

**三栏联动规则**：中栏产出的每一步结论都会在右栏生成对应证据卡；点击证据卡可回跳中栏对应的执行步骤（步骤 ↔ 证据双向定位）。

### 4.3 业务事件日历页

* 事件录入与维护：营销节点、大促活动、系统故障、政策变化、竞品动作；字段含名称、类型、起止时间、影响维度（渠道/品类/区域/客群）、备注。
* 时间线视图与筛选：按时间跨度、类型、指标域筛选。
* **关联视图**：展示某次异动窗口前后 3 日内命中的事件，并标注重合维度。

### 4.4 指标字典配置页

* 原子指标 / 派生指标 / 复合指标三类维护：名称、口径说明、公式、单位、精度、依赖字段。
* 复合指标必须绑定默认拆解层级树（树可拖拽编辑）。
* **口径校验**：保存时校验公式可解析、引用存在、结构为可加或可乘（比率型指标禁止作为分解对象）。
* 版本化：每次修改生成新版本，历史会话记录其使用的版本号。

### 4.5 报告归档与导出预览页

* 报告列表：按指标域、期间、生成人、状态筛选。
* 排版预览：按第七节的七段结构渲染整篇报告（图表可回链到工作台证据）。
* 批注编辑（单人）：在段落级添加批注，保留修改痕迹。
* 导出：Markdown / PDF / Excel；**导出内容与预览必须完全一致**（同一份结构化中间态渲染）。

## 5. 业务规则（细颗粒度）

### 5.1 指标口径规则

| 规则 | 内容 |
| --- | --- |
| GMV 口径 | **支付成功**且观察期内未取消/未退款的订单金额；下单未支付、取消、退款作为独立状态单列，不混入 |
| 时间归集 | 按**支付完成时间**归集到自然日（不用下单时间） |
| 金额存储 | 事实表金额以**整数分**存储（聚合无浮点误差）；展示与报告按元保留 2 位小数 |
| 分解计算精度 | 分解在 float64 上进行；守恒断言使用**相对误差**（见 5.2） |
| 用户口径 | UV 使用**去重用户 ID**（登录用户按 user_id，游客按 device_id）；同一会话内口径不得切换 |
| CVR | `支付订单数 ÷ UV`；分子分母口径必须在报告中同时展示 |
| 毛利口径 | `毛利额 = 营收 − 原材料成本 − 物流履约成本 − 渠道佣金 − 其他成本`，**全部为不含税口径** |
| 口径版本 | 指标定义版本化；会话、报告、评测记录均记录所用口径版本 |

### 5.2 指标树与分解规则

* **结构约束**：只对**可加**或**可乘**的结构做贡献率分解；比率型指标（毛利率、转化率等）只展示、不作为分解对象。
* **加法模型（差额分析）**：`ΔY = Σ Δxᵢ`；因子贡献 = `Δxᵢ`；贡献率 = `Δxᵢ / ΔY`。当 `ΔY = 0` 时贡献率不定义，只输出绝对贡献并在报告中说明。
* **乘法模型（LMDI）**：`ΔY = Σ L(Y₁,Y₀) · ln(xᵢ₁/xᵢ₀)`，其中 `L(a,b) = (a−b)/(ln a − ln b)`。要求所有因子严格大于 0；遇到零值时按预案处理（替换为极小值 ε 并在报告标注，或降级为分步差分法）。
* **混合树**：逐层分解，**每一层独立守恒**（外层加法、内层乘法），层与层之间不得交叉抵消。
* **守恒断言**：每层强制 `|Σ贡献 − Δ目标| / max(|Δ目标|, 1) < 1e-9`，并在报告与接口响应中输出实际残差（LMDI 的交叉残差必须为 0，报告中显式展示"残差 = 0"）。
* **误差与噪声**：守恒断言失败即为实现缺陷，不允许"约等于"通过；数值不稳定（如极端小基数）时输出置信提示而非静默估算。

### 5.3 维度下钻与贡献分摊规则

* **维度集合**：渠道、品类、区域、客群；支持任意组合交叉，单次交叉**最多 3 个维度**（控制组合爆炸）。
* **锁定切片**：下钻必须继承上一层锁定切片；扩大范围必须显式操作并写入会话记录。
* **TOP 组合定位**：按绝对贡献排序取 TOP N（默认 5），同时给出覆盖率（TOP N 贡献 ÷ 总变动）。
* **占比分摊**：对复合因子做维度归因时使用"按占比分摊"（即按维度占比分摊差值）。该方法是**启发式、非唯一解**，报告与手册中必须如实说明，不得包装成唯一正确值。

### 5.4 异动判定规则

* **对比方式**：支持环比（日/周/月）与同比；对比期间必须显式记录。
* **基线带**：基线 = 过去 4 周同时段中位数 × 季节性因子（季节性因子来自合成数仓的公开口径校准参数）。
* **判定阈值（默认值，可在配置中调整）**：变动幅度绝对值 > 5% **且** Z 分数（相对基线）> 2。
* **去噪要求**：判定结果必须输出"是否落在正常波动区间"，避免把噪声当异动；阈值调整留痕。

### 5.5 假设生成与验证规则

* **生成**：基于异动指标、一级因子贡献与下钻结果，生成 **3~5 条**候选假设；每条假设必须包含五要素——假设陈述、预期方向、验证口径、可执行探查代码草案、反例检查。
* **验证**：候选假设的探查代码在**安全沙箱**中执行（见 5.10），产出量化事实：数值、样本量、显著性、覆盖时间段。
* **置信度**：由三部分构成——显著性得分、效应量得分、数据覆盖度得分（权重固定并写入配置，可复现）。
* **排除规则**：置信度 < 0.6（默认）标记为"已排除"，并在 UI 与报告中保留排除原因，不得隐藏。
* **反例检查**：若假设为真，则其指向的维度子集应呈现一致方向；反例成立时置信度必须下调。

### 5.6 伪相关排除规则

伪相关指"两个量同步变化，但由共同原因驱动，或只是时间上的巧合"。四条检查手段必须按序执行：

1. **控制变量**：在同一维度切片内部重新检验关系是否仍然成立（若切片内不成立，则为共同驱动）。
2. **时间先行性**：原因必须早于或同步于结果；滞后时间不合理时下调置信度。
3. **安慰剂检验**：换一个同质性维度（预期不应成立）做同样检验；若同样"显著"，判定为共同驱动趋势。
4. **样本充分性**：样本量不足或覆盖时间段过短时，禁止下结论，只能标记为"证据不足"。

**输出要求**：每条被排除的假设都必须写明排除理由与使用的检验手段，理由文本进报告附件。

### 5.7 业务大事件因果关联规则

* **匹配窗口**：异动窗口**前后各 3 日**（可配置 1~7 日）。
* **匹配条件**：事件影响维度与异动维度**存在交集**，且时间落入窗口。
* **入链方式**：命中事件作为**外生解释变量**写入因果链，并标注"外部因素，非内部操作问题"，防止把外部干扰误判为内部执行问题。
* **禁止强行关联**：时间不符或维度无交集时不得关联；相关度低的事件只能作为"待观察"列出。
* **多事件竞争**：多个事件同时命中时，按"维度重合度 → 时间接近度"排序并列展示，不得只留一个而不说明取舍。

### 5.8 What-If 策略推演规则

* **模型**：单点弹性（按渠道/品类分别估计）+ 参数曲线（对单因子做区间扫描）。
* **输入约束**：只允许**可干预因子**（预算分配、价格、佣金率等）；不可干预因子（宏观、天气、竞品动作）禁止作为推演输入，只能作为情景注释。
* **取值范围**：限制在历史观测区间内（默认 ±30%），超出范围必须显式警告。
* **输出约束**：必须给出**区间**而不是精确承诺值，并附假设条件与把握度；禁止输出"预计提升 12.3%"式的无依据精确值。
* **可复现**：同一输入必须得到完全一致的输出（确定性计算、固定种子）。

### 5.9 会话与上下文规则

* **状态机**：`created → analysing → awaiting_user → completed`，失败走 `failed`；每次状态迁移落库。
* **上下文锁定**：锁定"指标 + 口径版本 + 对比期间 + 维度切片"；追问默认继承锁定项，变更需显式操作。
* **结果过期**：数据刷新或指标口径变更后，受影响结论标记为"结果过期"，必须重算才能进入报告。
* **并发隔离**：会话之间不得串上下文；同一会话同一时刻只允许一个执行中任务（第二个请求排队或拒绝并给出提示）。
* **中断与恢复**：任务支持暂停/取消；恢复时重新校验权限与数据版本，并记录恢复事件。

### 5.10 安全数据分析沙箱规则

* **隔离形态**：受限子进程——**无网络**、**只读数据库角色**、CPU/内存/执行时限配额、独立临时目录、环境变量白名单。
* **SQL 约束**：仅允许 `SELECT`；禁止 DDL/DML、多语句、注释绕过；限制最大扫描行数与结果行数。
* **Python 约束**：仅允许数值计算类库；禁用 `os`/`sys`/`subprocess`/`socket` 等危险模块与网络、进程、文件写入能力（沙箱临时目录除外）。
* **审计**：每次执行记录语句摘要、耗时、返回行数、退出码、拦截原因，写入审计表且不可删除。
* **硬拦截项**：越权读表（非授权 schema/表）、超配额、网络访问、写入业务表——一律拦截并留痕。
* **残余风险**：隔离等级与残余风险必须在技术规格与材料中如实声明，不得宣称"绝对安全"。

### 5.11 报告与导出规则

* **结构固定**：按第九节的七段结构输出，顺序不可变；每段必须标注数据来源与统计期间。
* **单一中间态**：一份报告对应一个结构化中间态（JSON），Markdown / PDF / Excel 三种格式由同一中间态渲染，**保证三格式与页面完全一致**。
* **结论绑定**：每条结论必须绑定量化贡献（数值 + 贡献率 + 证据链接）；行动项必须绑定责任岗位、预期完成周期、预期收益区间。
* **禁止泛化**：不得输出"加强运营、优化投放"这类无数据支撑的泛化建议。

### 5.12 数据合成与真值规则

* **可复现**：生成器使用固定种子，同一种子必须产出完全相同的数据集与真因清单。
* **真值预埋**：每次向数仓注入异动时，同步写入"真因记录"（日期、维度组合、驱动因子、真实贡献额、注入幅度）。
* **独立核算**：期望值由**独立路径**产生（生成器解析式 + 独立 SQL 校验），**严禁**用被测系统的分解结果反向充当期望值。
* **评测口径**：Top-1 命中率、Top-3 命中率、贡献额相对误差、伪相关陷阱的误纳率、越权拦截率。

## 8. 核心业务流程

### 8.1 L1 归因链路（异动 → 拆解 → 假设 → 验证 → 事件）

1. 用户在大盘发现指标异动，或在工作中台直接输入归因需求（自然语言）。
2. 系统解析目标指标、时间范围与对比基期，创建会话并锁定口径版本。
3. 读取指标树定义，完成第一级数学拆解与大盘拉动率计算（加法用差额分析、乘法用 LMDI），输出守恒残差。
4. 基于异动特征生成 3~5 条候选假设，在界面以假设卡片流呈现。
5. 为每条假设生成探查代码，在安全沙箱中并行执行多维交叉探查。
6. 计算置信度，过滤低置信假设（标记"已排除"并保留原因），执行伪相关四步检查。
7. 检索业务事件日历，匹配窗口内事件，作为外生变量补全因果链。
8. 输出归因结论（首要/次要原因、贡献额与贡献率）与证据链。

### 8.2 L2 下钻链路（多轮追问与深度探查）

1. 用户针对阶段性结论发起追问（例如"那这个渠道里，是哪个品类拖的"）。
2. 系统继承前序上下文（锁定切片、口径版本、期间），锁定异常切片。
3. 向下钻取细分指标与底层行为事实，逐层做守恒校验。
4. 动态更新看板与证据透视表；若新结论依赖新的假设，则回到 L1 的验证流程。
5. 数据或口径发生变化时，标记旧结论"结果过期"并提示重算。

### 8.3 L3 推演与交付链路（What-If → 报告）

1. 系统基于归因结果锁定**可干预**驱动因子，给出策略候选。
2. 用户在模拟器调节参数，系统实时推演目标指标区间与收益区间。
3. 系统组装七段式报告（异动背景、贡献拆解、下钻证据、核心结论、证据链与置信度、What-If 结论、行动清单）。
4. 用户预览、批注，确认后导出 Markdown / PDF / Excel；报告归档并记录所用口径版本与会话链接。

## 9. 结果与输出格式（七段式报告）

| 段 | 内容 | 必备字段 |
| --- | --- | --- |
| 1 异动背景与问题定义 | 目标指标、统计周期、基期值、现期值、总差异额与差异率 | 口径版本、对比方式 |
| 2 因子贡献率拆解 | 瀑布图 + 表格：各因子绝对贡献、贡献率、拉动方向、守恒残差 | 残差必须显式为 0（或标注未通过） |
| 3 细分维度下钻证据 | 异动最集中的 TOP 维度组合、透视表、关键变化特征、覆盖率 | TOP N 的 N 值与覆盖率 |
| 4 核心归因结论 | 首要原因、次要原因、内外部诱因划分 | 每条结论绑定贡献额 |
| 5 因果证据链与检验置信度 | 数据验证证据、沙箱执行摘要、显著性水平、伪相关排除记录 | 检验方法与样本量 |
| 6 What-If 情景模拟结论 | 不同策略下的目标指标预估区间与前提条件 | 区间、假设条件、把握度 |
| 7 可落地策略行动清单 | 业务动作、责任岗位、预估周期、预期收益区间 | 每条行动绑定驱动因子 |

## 10. 示例业务场景（两个，均为可端到端演示）

### 10.1 场景 A · 电商大促后 GMV 下滑归因

* **设定**：大促第 3 日 GMV 环比前一日 **−8.2%**。分渠道看，"付费投放"渠道 UV 上升 35% 但 CVR 下降 40%（高流量低转化占比提升）；同时某主力品类断货使 AOV 微降。
* **预埋真值**：渠道结构变化贡献 **−6.5pp**、品类断货贡献 **−1.2pp**、其余为噪声 **−0.5pp**（合计 −8.2pp）。
* **演示链路**：大盘发现异动 → 一键发起归因（L1）→ 生成并验证 4 条假设、排除 2 条伪相关 → 下钻到"付费投放 × 主力品类"（L2）→ 事件日历命中"竞品降价"与"平台流量券发放" → What-If 调整预算分配与佣金（L3）→ 导出报告。

### 10.2 场景 B · 快消品毛利额异动归因

* **设定**：本季度毛利额环比 **−11.0%**，其中营收仍在增长，但成本增速更快。
* **预埋真值**：原材料涨价贡献 **−6.8pp**、渠道佣金率上调 **−3.1pp**、物流履约成本上升 **−1.5pp**、价格结构改善 **+0.4pp**（合计 −11.0pp）。
* **演示链路**：外层加法分解定位成本项（L1）→ 内层乘法拆"销量 × 单位成本"（L1）→ 下钻到原材料品类与渠道（L2）→ 事件日历命中"原料价格公告"与"渠道政策调整" → What-If 推演佣金率与售价调整组合（L3）→ 导出报告。

### 11.2 本项目自行增加的验收标准（扩写，均可测）

| 编号 | 验收项 | 判定标准 |

| E1 | 归因准确率 | 评测集上输出 Top-1 / Top-3 命中率与贡献额相对误差；**首次实测后确定基线并留档**（参考目标：Top-1 ≥ 70%、Top-3 ≥ 90%、贡献额相对误差中位数 ≤ 5%） |

| E6 | 导出一致性 | 同一份报告的三格式导出与页面内容字段级一致（自动比对） |
| E7 | 可复现性 | 固定种子重跑评测，指标波动在 ±1pp 内；相同 What-If 输入输出完全一致 |

## 15. 已确认的关键设计决策

全文 21 条决策见 [`00-项目共识确认书.md`](00-项目共识确认书.md) 第三节。与需求直接相关的六条：

1. **原文验收标准为下限**：8 条全做，再按七类维度扩写（第 11.2 节）。
2. **只对可加或可乘结构分解**：比率型指标只展示不分解（5.2）。
3. **守恒是硬约束**：每层相对误差 < 1e-9，失败即缺陷（5.2、E2）。
4. **大模型只出草案**：数值由确定性算法产出，结论必须落到可复现查询（0.1、7）。
5. **沙箱是受限子进程**：无网络、只读角色、配额受限、全量审计，残余风险如实声明（5.10）。
6. **数据全合成但带真值**：期望值由独立路径核算，准确率类指标明示基于合成数据集（0.1、5.12）。
