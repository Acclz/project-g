# 产业口径与来源清单

> 版本：v1.0（P1）　｜　验证日期：2026-09-15
> 用途：合成数仓里的"行业感"不能凭空捏造。**凡是有权威来源的参数，都标出来源与日期；拿不到来源的，一律显式标注"自定参数"，不伪装成行业事实。**

## 1. 调研方法（为什么不用搜索引擎）

* 实测：`html.duckduckgo.com` 完全不可达；`cn.bing.com` 可用但**精确检索质量差**——查"中华人民共和国招标投标法 全文"返回的是香烟品牌页面。因此**不把通用搜索引擎当作证据来源**。
* 采用：**权威站点直连 + 站点内检索**；每条参数记录「来源 URL + 抓取日期 + 用于哪个参数 + 是否自定」。
* 所有校准参数汇总落盘到 `corpus/warehouse/calibration.csv`（P2 建立），文档与数据文件必须一致。

## 2. 已验证可达的来源（2026-09-15 实测）

| 站点 | 实测结果 | 本项目用途 |
| --- | --- | --- |
| `https://www.stats.gov.cn/`（国家统计局） | 200 | 社会消费品零售总额（月度，分品类）→ 季节性因子、品类结构；PPI（工业生产者出厂价格）→ 原材料成本波动；居民消费价格 → 售价指数参考 |
| `https://www.mof.gov.cn/`（财政部） | 200 | 政府采购与财政政策口径；企业内控相关规范文号核查 |
| `https://www.cninfo.com.cn/`（巨潮资讯） | 200 | 上市公司年报/招股书 → 电商平台佣金率区间、快消企业费用率与单位成本结构的**真实披露值** |
| `https://www.spb.gov.cn/`（国家邮政局） | 200 | 快递业务量与业务收入月度数据 → 单票均价（物流履约成本校准） |
| `https://www.samr.gov.cn/`（国家市场监督管理总局） | 200 | 企业登记与行政处罚口径参考（渠道商/供应商状态类字段设计） |
| `https://www.gov.cn/`（国务院公报） | 200（P1 早前实测） | 法规原文与政策口径 |
| `https://fgk.chinatax.gov.cn/`（国家税务总局法规库） | 200（P1 早前实测） | 税率、发票与抵扣口径（快消成本核算的不含税口径依据） |
| `https://gsxt.gov.cn/`（国家企业信用信息公示系统） | 200（P1 早前实测） | 主体存续状态与经营异常名录（供应商/渠道商字段设计参考） |

## 3. 不可达与空档（如实记录）

| 目标 | 状态 | 处理 |
| --- | --- | --- |
| `www.chinawuliu.com.cn`（中国物流与采购联合会） | **SSL 握手失败** | 物流费率改用国家邮政局数据；联合会数据标为"不可得" |
| `html.duckduckgo.com` | 不可达 | 不使用 |
| `www.baidu.com` | DNS 解析偶发失败 | 不使用 |
| 平台级真实佣金率/转化率（如各电商平台内部口径） | 无公开权威来源 | **标注"自定参数"**，并在评测与报告中声明为模拟值 |

## 4. 参数 → 来源映射（P2 建立 `calibration.csv` 时按此填）

| 数仓参数 | 取值来源 | 当前状态 |
| --- | --- | --- |
| 季节性因子（按月） | 国家统计局社会消费品零售总额月度序列（同比与环比形态） | 待抓取（P2） |
| 大促倍率（`promo_lift`） | 平台公开战报/行业报道；若无权威数值 | **自定参数**（默认大促日 ≈ 平日 2.2–3.5 倍） |
| 品类结构（12 品类占比） | 国家统计局社零分类 + 上市公司品类结构披露 | 待抓取（P2） |
| 平均单价（电商） | 自定（合成场景），量级参考公开行业报道 | **自定参数** |
| 渠道佣金率 | 巨潮资讯年报/招股书披露的佣金与收入比例 | 待抓取（P2） |
| 物流单票成本 | 国家邮政局快递业务收入 ÷ 业务量（月度） | 待抓取（P2） |
| 原材料单位成本波动 | 国家统计局 PPI 分项（同比形态） | 待抓取（P2） |
| 客群定义与占比 | 无权威口径 | **自定参数** |
| 转化率区间（CVR） | 无权威公开来源 | **自定参数** |

## 5. 使用规矩

1. **报告与演示中引用行业数值时，必须能指到上表**；指不到的一律说"这是我们自定的模拟参数"。
2. 抓取到的序列只取**形态与量级**（如季节性、同比变化率），不直接搬运原始数值；原始数值附 URL 与抓取日期备查。
3. 每次校准参数变更，都要在 `03-进度与质量.md` 记录"改了哪个参数、依据什么、影响哪些指标"。
4. 待 P2 完成抓取后，本文件升级为 v1.1 并标注每条参数的最终来源与日期。
