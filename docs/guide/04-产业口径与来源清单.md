# 产业口径与来源清单

> 版本：v1.1（P2 完成抓取，147 条参数全部落盘）　｜　验证日期：2026-09-15
> 用途：合成数仓里的"行业感"不能凭空捏造。**凡是有权威来源的参数，都标出来源与日期；拿不到来源的，一律显式标注"自定参数"，不伪装成行业事实。**

## 1. 调研方法（为什么不用搜索引擎）

* 实测：`html.duckduckgo.com` 完全不可达；`cn.bing.com` 可用但**精确检索质量差**——查"中华人民共和国招标投标法 全文"返回的是香烟品牌页面。因此**不把通用搜索引擎当作证据来源**。
* 采用：**权威站点直连 + 站点内检索**；每条参数记录「来源 URL + 抓取日期 + 用于哪个参数 + 是否自定」。
* 所有校准参数汇总落盘到 `corpus/warehouse/calibration.csv`（**P2 已建立：147 条**），文档与数据文件必须一致。
* **P2 新增实测**：`data.stats.gov.cn/easyquery.htm`（统计局数据查询接口）返回 **403**，拿不到结构化月度序列；
  改从 `stats.gov.cn/sj/zxfb/`（数据发布）正文取数，能取到的是当月值与累计同比，取不到 18 个月的逐月原值。
  这类"取到什么就写什么、取不到就标自定"的处理，是本文件存在的意义。

| 大促倍率（`promo_lift`） | 平台战报无统一权威口径 | **自定参数**（年货节 2.2 / 6·18 2.6 / 99 1.4 / 双11 3.2 / 双12 1.6） |

### 4.1 参数分级统计（`calibration.csv`，147 条）

| 来源类型 | 条数 | 含义 |
| --- | --- | --- |
| 权威来源 | 29 | 直接来自国家统计局发布稿的数值（含两条发布稿的原始数字） |
| 派生计算 | 9 | 由权威数值按公式算出（如 84195 ÷ 327569 = 25.66%） |
| 近似映射 | 7 | 社零分类与我方品类名不完全同名，按最近口径映射并逐条标注 |
| 自定参数 | 102 | 无权威公开口径，全部在 `source_name` 里写明"自定参数" |

校验规则落在代码里（`app/warehouse/calibration.py`）：权威/派生/映射三类必须带 URL 与抓取日期，
自定参数必须显式标注，权重类参数必须闭合到 1——不满足则**加载即失败**，不让坏参数流进数仓。

## 6. 使用规矩

1. **报告与演示中引用行业数值时，必须能指到上表**；指不到的一律说"这是我们自定的模拟参数"。
2. 抓取到的序列只取**形态与量级**（如季节性、同比变化率），不直接搬运原始数值；原始数值附 URL 与抓取日期备查。
3. 每次校准参数变更，都要在 `03-进度与质量.md` 记录"改了哪个参数、依据什么、影响哪些指标"。
4. 待 P2 完成抓取后，本文件升级为 v1.1 并标注每条参数的最终来源与日期。
